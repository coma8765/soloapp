# Первоначальная установка

Публичный репозиторий содержит конфигурации для обслуживания уже подготовленного стенда. Исторические одноразовые migrations остаются локальными и не публикуются.

Создайте собственные VM/IAM, WireGuard, PostgreSQL и сертификаты перед запуском `infra/ansible/site.yaml`. Локальные inventory и cloud IDs заполняются из example-файлов. Playbook не является автоматическим provisioning с нуля.
