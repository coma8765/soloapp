# Общий чат

После login Flutter открывает общий чат всех аккаунтов. API описан в `api.yaml`, Nest routes и Dart client генерируются из него. GET `/api/v1/app-api/v1/chat/messages` возвращает последние 100 сообщений в хронологическом порядке; POST того же пути принимает `{text, client_id}`. `user_id` берётся только из проверенной HMAC-личности nginx/auth, переданный клиентом user_id отвергается. Gateway проверяет сессию при каждом запросе, поэтому logout отзывает доступ к чтению и отправке.

Каждый pod Nest публикует и читает один Redis Stream через Sentinel. `client_id` — 32 hex символа, используется для идемпотентного повтора от того же пользователя в течение суток. Redis Lua атомарно проверяет dedup, квоту 10 сообщений / 10 секунд на user и записывает сообщение. 1..1000 символов, текст без HTML-интерпретации. Сетевая ошибка не вызывает автоматического повтора POST; ручной повтор того же текста использует прежний client_id. Во время failover ответ 503, затем клиент возвращается к чтению раз в 2 секунды. Это polling-чат, не WebSocket; на каждый read выполняется обычная авторизация.

Redis credentials читаются из `REDIS_CONFIG_FILE` (по умолчанию tmpfs secret sidecar). Изменение файла переоткрывает pool, ошибки не раскрывают credentials. История ограничена 500 записями, dedup 24ч; последние сообщения могут потеряться при отказе из-за async replication. Нет личных комнат и приватных сообщений: текст виден всем вошедшим аккаунтам.
