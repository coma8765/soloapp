# Работники операторской

Семь работников выбирают случайные цели в свободной области БЩУ вместо обхода по кольцу. У каждого свой seed и сдвиг времени; цель меняется примерно раз в 45 секунд. После достижения цели работник ждёт следующей. Скорость ходьбы — 0,7 м/с.

Навигационная сетка строится по реальной геометрии мебели с шагом 0,6 м и запасом 0,43 м. Используется крупнейшая связная область; цели у дверного проёма исключены. Пути сглаживаются только там, где прямая не пересекает мебель или человека. При появлении препятствия работник перестраивает путь либо ждёт, затем продолжает движение. Перестроения ограничены по частоте и разнесены между работниками.

Участник и работники имеют горизонтальный радиус 0,35 м. Непрерывная проверка всего перемещения останавливает их до пересечения даже при длинном кадре. Столкновения с людьми и панелями решаются вместе: обход человека не должен проталкивать участника в пульт. Работники также учитывают друг друга, главного инженера и полученные позиции удалённых участников БЩУ. В других комнатах их коллайдеры отключены.

Случайные цели и начальные позы вычисляются по общему серверному времени. Обход препятствий выполняется на клиенте по известным ему позициям людей: это не авторитетная серверная симуляция NPC; при сетевых задержках обход у клиентов может временно различаться. При первой привязке к серверному времени и повторном входе начальные позиции выбираются вне занятых мест. Движение после длинной паузы ограничено 0,1 секунды за обновление, без скачка через людей.

## Проверка

```sh
node --test services/soloapp_app/tests/workers.test.mjs services/soloapp_app/tests/room-collision.test.mjs
```

Для браузерной проверки запустить статический сервер каталога `services/soloapp_app/public`, установить Playwright и Chrome, затем:

```sh
SOLOAPP_BASE_URL=http://127.0.0.1:4193 node services/soloapp_app/tests/workers-browser.cjs
```

Проверяются два клиента, совпадение начальных поз по серверному времени, случайные маршруты по реальной мебели, длительная прогулка, встречные столкновения, продолжение движения после освобождения пути, удалённые участники, смена комнаты и реплики работников. Ввод XR проверяется без физического шлема.
